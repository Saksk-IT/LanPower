# Codex Remote 完整输入与功能对齐

Windows / Cloud / Web `1.21.0`，微信小程序 `3.2.0`。项目以 Codex Remote 为核心，电源控制和唤醒为远程开发提供配套能力；功能设计、传输和验收以完整远程开发体验为目标。

## 已移除的额外限制

| 内容 | 旧限制 | 当前行为 |
| --- | --- | --- |
| 图片附件 | 最多 4 张；每张 700000 字符，合计 850000 字符；网页原文件 20 MB | 不设图片数量、大小或总量上限，保留原始字节、尺寸和动画，删除自动压缩 |
| 输入与技能 | 文字及文件引用 16000 字，8 个技能，合计 13 项输入 | 不设上述长度/数量上限；长文字直接粘贴，技能按原生目录校验 |
| 大消息与回复 | 请求 1 MB，结果 16 MB，最多 512 段，客户端组装 32 MB | 原始请求和结果分块传输，不设逻辑消息总大小或分段数量上限 |
| 附件类型 | 网页仅图片 | 网页普通文件、文件夹及小程序普通文件可上传至目标 Windows 用户的附件目录，保留原文件字节，引用后交给 Codex |
| 队列 | 超过 32 条无法排序 | 不设队列排序数量上限，校验编号及顺序 |
| 项目与目录 | 手动目录 32 个；自动项目 256 个、部分数据源 128 个；能力默认只覆盖 8 个项目 | 删除这些数量限制，读取完整授权项目与能力目录 |
| 项目组织与目录 | 64 个置顶；1024 个组织项；聊天摘要总量 100000 条；能力目录 10000 项/4 MB | 删除这些数量/大小拒绝，继续游标分页 |
| 文件与图片读取 | 图片预览 8 MB；文件预览 1 MB；目录 4001 项；搜索 5000 项/深度 6/50 个结果 | 不设上述拒绝或裁剪；目录继续分页，搜索完整普通项目文件，排除依赖和版本库内部目录 |
| 历史与状态 | 单项超过 64 MB拒绝；4096 个引用；Diff 裁剪到 262144 字符，文件变化只保留 32 项 | 删除这些拒绝及正文裁剪，缓存淘汰后按稳定引用重读原内容 |
| 审批与回执 | 回答数/回答文字上限，64 个待审批，512 个回执 | 删除这些数量和文字限制；保留会话、权限和发送结果核验 |

模型与原生 Codex 的实际支持范围仍由当前电脑上的 Codex 决定。身份、授权目录、会话绑定、图片格式、重复键、协议字段及审批语义继续校验。分页每页数量、缓冲背压、可重读的缓存淘汰、断线清理与超时属于传输和恢复机制，不限制能提交或最终读取的内容总量。

## 发送与文件上传

图片新增、粘贴、编辑队列、从历史或草稿恢复均保持原图。准备时保留会话代次检查，切换会话不会把旧草稿发到新会话。完整上传及校验成功后才派发，未发送失败恢复草稿；结果待确认时查询回执，不自动重发任务。

微信相册选择器一次可选 9 张，这是微信选择器的批次范围；可以重复添加，草稿没有数量上限，选择原图。文件选择同样可以多批次累积。

普通文件仅落在目标 Windows 用户的 `%LOCALAPPDATA%/LanPower/CodexAttachments/<随机编号>`，不写 Cloud。上传要求目标项目已经授权；文件名称拒绝路径、NTFS 流和穿越，新建文件不覆盖现有文件。发送引用时使用完整电脑路径。上传文件作为用户提供的附件处理，不改变电脑现有权限策略；附件按普通文件保留，移除草稿引用不会删除电脑文件。

## 原生功能覆盖

取消额外限制与接入全部原生功能是两项工作。当前已经接入原会话、输入、图片/文件、历史、模型、思考强度、计划模式、权限切换、队列、审批、额度/上下文、技能、插件/应用/MCP 目录和 MCP 重载。

仍需继续接入的功能包括自动化创建/编辑/调度、插件安装与 OAuth、账号/提供商设置、Git 分支/工作树管理、独立终端、文件补丁撤销/重做和语音。这些是功能实现缺口，不能用“解除上传限制”宣称已经 100% 对齐。后续以这些原生开发流程为验收目标，详见 [系统对齐](codex-system-parity.md)。

## 验证

自动验证覆盖 10–12 张大原图、20 个技能、十万字 Unicode 输入、超过 20 MB 的原始请求/普通附件、超过 16 MB 和 512 段的回复、100 条队列排序、完整文件读取、拒绝跨目录上传、分块乱序/重复/身份变化及失败草稿恢复。

真实浏览器使用隔离接口验证原图字节一致、编辑队列、10 张原图、长文字、普通文件、仅图片发送、拒绝恢复以及 1440/390/320px 布局。云端测试使用真实认证 WebSocket 与中继，验证完整到达后才派发和正文不写数据库；电脑端测试使用隔离目录验证上传字节与路径边界。

这些自动验证不代表用户原会话已执行新的推理任务，也不代表微信真机和公网 5G 已验收。部署和最终验证记录见 [本机开发环境](local-development.md)。`1.20.2` 的四图压缩方案已由本版原图分块传输替换。
