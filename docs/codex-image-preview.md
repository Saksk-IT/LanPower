# Codex Remote 图片折叠预览（1.18.1）

Windows / Cloud / Web `1.18.1`，微信小程序 `3.0.2`。工作过程图片采用与命令详情相近的可折叠展示，避免长截图直接撑开整个对话。

- 查看图片显示「已查看 1 张图像」，生成图片显示「已生成 1 张图像」，默认收起。
- 点击标题展开 140×140 的预览框，按原比例缩放，完整显示横图或长图；再次点击标题收起。
- 网页点击缩略图打开既有大图预览，可关闭、按 Escape 返回并下载原图；小程序点击缩略图打开微信原生图片预览。
- 收起时网页不创建图片读取组件，小程序不发起图片读取；展开后按现有授权读取图片，读取失败可点击重试。
- 同一会话刷新保留展开状态，切换会话重新收起。图片正文、用户附件和最终答复中的 Markdown 图片继续使用既有展示。

Cloud 继续使用有界内存中继；不新增图片落盘、正文缓存或额外文件权限。版本更新和本机安装继续保留数据库、配置、配对及授权。
