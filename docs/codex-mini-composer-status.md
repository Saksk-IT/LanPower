# 小程序输入区、上下文与模型强度

2026-10-06：微信小程序 `3.6.11`，配套 Windows / Cloud / Web `1.24.6`，协议版本保持 `2`。

文件更改气泡与“返回最新消息”按钮位于输入区上方同一行，使用正常布局跟随输入区高度，不再使用固定的底部偏移。多行输入、附件、排队消息和键盘出现时，按钮仍完整位于输入框之外。外围保持透明并允许触摸正文；回到底部后继续沿用原来的自动跟随规则。

输入工具栏右侧分别显示上下文圆圈、模型强度仪表盘和发送 / 停止按钮。

紧凑输入框以同一行垂直居中布局显示加号、24px 高的单行输入文字和右侧状态 / 发送图标，保持原生输入控件的字形位置，避免额外顶部偏移或文字内边距造成高低错位。聚焦或输入多行内容后继续使用展开输入区。

- 上下文圆圈读取当前会话的原生 `thread/tokenUsage/updated` 通知，以最近一次上下文用量除以模型窗口计算占用弧线。上下文压缩后弧线随真实用量缩短；不使用累计 token 用量。点击查看上下文和工作状态。
- 缺少会话用量或模型窗口时显示灰色待确认圆圈；切换会话、切换电脑和断线时不会冒用旧会话的比例。
- 仪表盘单独打开模型与模型强度选择。强度按从低到高排列，指针向右移动，蓝色弧线从左侧起点延伸并准确终止在指针方向。浅色与深色模式同步更新。
- 仪表盘读取原窗口设置及已选择的下次任务参数；没有明确强度或模型默认强度时不伪造指针。恢复原窗口参数后重新显示原生强度。排队和引导继续沿用当前任务参数。

本机重新编译 `mini_program`，或导入 `windows/out/CodexDock-mini-program-3.6.11.zip`。导入包使用公开占位 AppID 与最小本机 HTTP 调试设置，保留现有账号和授权。
