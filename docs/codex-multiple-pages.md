# Codex Remote 多页面共享控制（1.16.2）

Windows / Cloud / Web 为 `1.16.2`，小程序为 `2.1.8`。已解除每台电脑只能连接一个远程控制页面的限制。多个已授权网页和小程序可以同时连接同一电脑，读取同一会话，使用既有发送、引导、暂停和原生队列操作。

## 使用方式

本机 Docker 和 Windows 已更新。刷新当前网页后，可再打开一个 Codex Remote 页面，选择同一电脑和会话。微信原生客户端需要重新导入、预览或上传 `2.1.8` 源码；本轮未上传微信公众平台。连接旧版 Cloud 收到 4409 时，新客户端会提示更新 Cloud。

任务属于目标电脑上的原 Codex 会话。多个页面查看同一任务时会收到相同进度；暂停、引导或审批会影响该任务，并同步给其他页面。原有活动任务检查、队列和一次审批约束继续适用；重复点击不会让同一审批执行两次。关闭一个页面不影响其他页面，也不会终止已经在电脑上运行的任务。

## 实现与授权

- 同一设备的页面共享一个 Host 会话，新增页面不会重复发送 `open`；最后一个页面离开时才发送 `close`。
- Cloud 将普通请求改用唯一转发编号，再只将回包还原给发起页面。不同网页或手机即使用了相同编号，也不会串页。
- 大响应仍按原有上限分段转发。客户端检查外层页面编号、正文转发编号和各段顺序，不要求 Cloud 拼接正文。
- 状态、任务通知和审批向所有页面同步，新增页面补发仍待处理的审批。同一审批在 Cloud 中只允许一个在途决定；失败回执只发给对应页面，处理完成通知同步移除全部页面的审批。
- 撤销设备关闭全部页面；撤销手机开发权限仅关闭对应手机连接。电脑 Agent 重连后清理旧路由、恢复所有页面，不重发任务。
- 登录、Origin、手机 Bearer、电脑归属、项目授权、请求白名单和内存上限继续校验。单个慢页面队列溢出只断开该页面。

协议子版本保持 `lanpower.codex.v1`，审批正文仅在有界内存保存，不进入数据库、日志或 PWA 缓存。具体字段见 [Relay 协议](codex-remote-protocol.md)。
