# 手机 5G / 外网控制方案

状态：方案评估，尚未开发或完成 5G 实测。当前 v1.0.1 仍只支持同一局域网。

## 现状与关键限制

当前小程序通过配对二维码保存电脑的内网地址和令牌，向 `http://内网地址:48211` 发送在线状态与电源指令；“开机”则由手机向家中网段发送 UDP WOL 广播。手机改用 5G 时，没有到家中内网地址的直接路由，广播也不会跨公网到达目标网卡。即使给目标电脑安装 VPN 或隧道，电脑关闭后，运行在电脑上的远程入口也会关闭。

因此，远程完整控制需要同时解决两件事：

1. 为手机提供经过身份验证的远程命令通道。
2. 家中有一台电脑关闭时仍在线的设备，在家中网段代发 WOL 唤醒包；电脑开机后，它再把其他指令转交给现有 LanPower 服务。

已验证的局域网 WOL 配置可以继续使用；新工作主要集中在远程通道、常在线网关及手机端切换逻辑。

## 两条实施路径

| 路径 | 适用前提 | 能力与代价 |
| --- | --- | --- |
| 路由器自带远程唤醒功能 | 具体型号和固件明确支持外网鉴权后触发 WOL | 开机部分可能无需新增硬件；在线状态和关机等操作仍需安全的远程访问通道。可能要在路由器 App 与现有小程序之间切换。 |
| 常在线家庭网关 + HTTPS 命令入口 | 路由器能运行受支持的服务，或家中有 NAS、软路由、树莓派等 | 可将开机、状态、睡眠、休眠、重启和关机统一到小程序；需要部署网关程序、远程服务及身份验证。 |

若想继续使用同一个微信小程序，建议优先评估第二条路径：

```text
手机微信小程序（5G）
      ↓ HTTPS + 用户身份验证
远程命令服务
      ↑ 家中网关主动建立的连接或定期取指令
小米路由器（若型号支持运行网关程序）/ 其他常在线设备
      ├─ 电脑关闭：在家中局域网发送 WOL 魔术包
      └─ 电脑在线：调用现有 LanPower 本地接口
```

家中网关主动连接远程服务时，可避免依赖家庭公网 IPv4 地址和入站端口映射。Tailscale 子网路由或 Cloudflare Tunnel 可作为远程接入组件，但它们本身不会在目标电脑关闭后替它发送 WOL；仍须有家中的常在线设备代发。若只求个人快速使用，也可由手机 VPN 访问家中受保护的网页控制入口，并让网关提供唤醒功能；这条路径不应直接假定现有微信小程序能通过 VPN 访问私有 IP。

## 实施前要确认

1. 家中路由器为小米 AX3000E。需在当前固件的管理页面确认是否具有可用的远程 WOL 功能或受支持的第三方运行环境；[小米官方产品页](https://www.mi.com/xiaomi-routers/ax-3000e)未给出这两项能力的明确说明。小米不同型号的 VPN 能力也不同，不能仅凭品牌判断。
2. 是否必须全部操作都留在微信小程序内；若可以接受浏览器或路由器 App，初版可更简单。
3. 若使用微信小程序访问远程服务，需按微信小程序当前网络规则准备可用的 HTTPS 域名、证书和后台域名配置，并以真机 5G 实测。现有内网 HTTP 地址不能直接作为公网接口。
4. 确认家中路由器、网络和代发设备在电脑关闭时仍通电联网。

不建议把现有 `48211` 端口或 UDP 9 端口直接映射到公网。远程入口应限制允许的用户和命令、使用独立凭证，并保留必要的审计与频率限制。家中网关持有本地 LanPower 配对密钥即可；不要把现有配对链接当作公开接口的唯一防护。
