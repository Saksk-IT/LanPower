# Codex Remote 完整会话显示（1.16.1）

Windows / Cloud / Web `1.16.1`，小程序版本标识 `2.1.7`。本次修复网页端含生成图片的会话整轮消失，取消所有会话内容下载和 JSON 导出入口。正文、图片及工具详情直接在会话中读取；桌面和手机浏览器使用相同逻辑。

## 已确认的原因

原窗口某条设计会话的第一轮可见内容约 4.3 MiB，包含三条各约 1.4 MiB 的图片生成记录，以及一条仅 551 字的最终答复。原窗口适配器先检查整轮超过 2 Mi 字符，再检查单项大小，因此图片使整轮被替换为 `lanpowerLargeItem` 引用。网页只在对话区外展示下载按钮，没有将引用还原为会话消息；正常答复及正文里的三张图片链接一起消失。原生会话记录未损坏。

## 当前行为

- 先分离大项再判断整轮大小，图片不再把旁边的普通正文一起隐藏。
- 打开会话、刷新、恢复连接、读取更早消息或跳至开头时，网页自动读取所需分段，检查顺序、总长度和条目标识，再将原始项或整轮放回原来的位置。旧 Host 返回的整轮引用也能自动恢复。
- 大项读取中显示临时进度；连接恢复后继续已经完成的分段。失败自动重试，过期引用自动重新读取对应轮次，用户无需保存或打开文件。
- 保留完整原文和命令输出；工作过程及命令详情仍可折叠展开。网页搜索、工具调用及新的可见条目都有详情，避免未知类型被静默丢弃；隐藏推理和内部压缩上下文不作为公开正文传输。
- 相同内容刷新时复用当前引用及已还原数据，避免重复读取和图片闪烁。切换会话或电脑会取消旧读取，迟到分段不能写入新的会话。瞬时断线保留已加载图片；切换电脑和撤销权限仍清理图片缓存。
- 跳至对话开头时暂停当前页的大项读取，优先定位历史；更早的完整内容通过滚动加载或历史分页查看，不以下载代替阅读。

分段是内部传输方式，既有会话授权、目录授权、单控制端和有界内存中继继续适用。Cloud 不存储对话，PWA 不缓存正文；历史来源仍为当前用户电脑的原 Codex 会话。图片引用保留当前会话的路径来源，不能借其他会话读取外部文件。

微信原生页面本轮仅同步版本标识和验证协议兼容，历史窗口及附件能力的 P1 改进另行实施。本次手机阅读验证指响应式网页，不等于微信真机或 5G 验收。

## 复验

```powershell
cd remote_ui
npm test
npm run build
cd ..
dotnet test windows/LanPower.UnitTests -c Release --filter "FullyQualifiedName~Codex|FullyQualifiedName~DesktopCdp"
node tests/test_codex_history_content_browser.cjs
node tests/test_codex_system_browser.cjs
node tests/test_codex_p0_browser.cjs
```

新增浏览器脚本默认使用独立公开样例，不连接真实控制端、不发推理任务。设置 `LANPOWER_NATIVE_DESIGN_FIXTURE` 可回放忽略目录中的原会话公开图片和答复；真实记录不纳入仓库。

2026-10-04 验证通过：Web 45 项自动测试、类型检查和生产构建；Windows 28 项 Codex/CDP 检查；Cloud 9 项版本兼容检查及小程序协议兼容脚本。原会话公开数据回放确认 551 字答复、三张生成图片及答复中引用的三张 Markdown 图片完整显示，1440/390px 下无下载事件和页面异常，并覆盖断线续读、引用过期重取、刷新复用和切换会话的迟到分段隔离。既有系统、会话与 P0 浏览器检查通过，包含 180 轮历史、1320010 字命令输出、17 MiB 单项直接查看和 320px 布局。
