# 微信小程序页面结构与导航

小程序 **3.4.2**；配套 Windows / Cloud / Web **1.22.2**。日期：2026-10-05。

打开小程序默认进入 **Codex** 工作台，主导航按「Codex / 电脑与电源 / 连接与设置」排列。项目、最近聊天与开始新会话保留在首页；电源管理用于支持开发电脑，局域网与旧版连接收进辅助入口。

Codex 首页与会话页使用自定义顶部导航，原有菜单、搜索、返回和聊天操作直接进入顶部栏，按状态栏与微信胶囊留出安全空间。页面不再额外显示「Codex Remote」标题栏；弹出菜单和窗口尺寸变化同步适配，详见 [顶部导航](codex-mini-navigation.md)。

## 页面路径

| 页面 | 路径 | 用途 |
| --- | --- | --- |
| Codex 首页与会话 | `pages/codex/codex` | 默认首页，选择电脑、项目与聊天，发送消息、处理队列和审批 |
| 电脑与电源 | `pages/power/power` | 当前电脑状态、唤醒与电源操作，电脑局域网关联和唤醒参数 |
| 连接与设置 | `pages/settings/settings` | 手机授权、开发版测试地址、电脑选择、帮助与旧版入口 |
| 使用帮助 | `pages/help/help` | Codex 接入、授权权限、局域网电源与唤醒说明 |
| 独立局域网 / 旧版连接 | `pages/index/index` | 无需 Cloud 的局域网电源管理及既有 v1 远程配对 |
| 旧 Cloud 入口 | `pages/cloud/cloud` | 兼容旧链接，只负责跳转到对应的新页面 |

旧 `?tab=home`、`?tab=devices` 跳转到电源页，`?tab=connect` 到设置页，`?tab=help` 到帮助页；未指定旧页签时进入 Codex。已有 `?computer=...` 电脑链接继续支持，目标会经当前授权电脑列表确认。

## 使用流程

1. 首次打开 Codex 首页，点击「连接 Codex」。
2. 在「连接与设置」扫描 Cloud 手机授权码。Cloud 须为这部手机开启 **Codex Remote** 权限；电源权限独立授权。
3. 授权成功直接返回 Codex 首页。选择开发电脑与项目或聊天，继续原窗口中的任务。
4. 需要开机或管理电源时进入「电脑与电源」。页面默认使用 Codex 所选电脑；返回后继续原聊天。
5. 开发版 Cloud 测试地址位于「连接与设置 → 开发版 Cloud 地址」，正式版与体验版仍使用各自授权。

辅助页面保留 Codex 页面在页面栈中，返回复用原页面。进入辅助页或切到后台时停止手机端连接、计时和控制状态；返回同一电脑后重新同步原聊天，保留内存中的草稿和附件，不重发任务。系统关闭小程序或切换授权后，聊天正文和未发送内容不会从本地持久恢复。

## 电脑与授权状态

Codex、电源和设置共用原来的环境隔离电脑缓存，仅保存电脑标识、名称与当前选择。显式电脑链接优先，其次使用同一环境、Cloud 地址和手机身份下最近选择的电脑，再选择当前授权列表中的第一台 Windows 电脑。切换电脑后先清除旧控制状态，再读取新电脑；目标不再授权或没有电脑时退出旧目标。

切换测试 Cloud、重新扫码为不同手机身份授权或移除授权时，返回 Codex 会重新加载当前身份。原正式版凭据、开发版各测试地址的凭据、局域网配对与唤醒设置沿用；缓存的设备状态不会直接开放控制。

设置页只读取已授权电脑，帮助页无需连接；电源状态轮询仅在电源页可见时运行。局域网直连与 WOL 用于电源管理，Codex Remote 仍使用原有 Cloud HTTPS/WSS 链路。离线唤醒入口仅在有可用唤醒方式时显示，发送成功仍需等待电脑上线且 Windows 用户登录。

## 验证与真机检查

导航检查覆盖默认首页、旧路径兼容、页面栈返回、共享电脑选择、环境与身份隔离、授权回流以及迟到的设备列表。现有 LAN / Cloud / Codex 检查验证电源路由、回执、聊天草稿、队列与授权边界；微信 WCC/WCSC 编译与 320/390/430px 自动渲染检查覆盖 Codex、设置、电源、帮助、浅深色与键盘布局。

自动渲染使用编译页面和虚构接口数据，不等同于微信真机验收。导入本机 `windows/out/CodexDock-mini-program-3.4.2.zip` 后，应在手机检查默认首页、顶部菜单与搜索、会话页返回和聊天操作、扫码返回、辅助页返回、切换电脑与网络恢复。真实扫码、5G、WSS、附件返回和电源动作由人工验收。
