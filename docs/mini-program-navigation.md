# 微信小程序页面结构与导航

小程序 **3.5.0**；配套 Windows / Cloud / Web **1.23.1**。日期：2026-10-05。

默认进入 **我的设备**，底部使用微信原生导航栏，仅有 **我的设备 / 我的** 两个页签。点击设备进入二级详情页，在详情中执行电源操作或进入该设备的 **Codex 控制**。详情、Codex、帮助与旧版局域网页面不显示主导航栏。

## 页面路径

| 页面 | 路径 | 用途 |
| --- | --- | --- |
| 我的设备 | `pages/devices/devices` | 默认首页，已授权 Windows 设备列表和状态，点击打开设备详情 |
| 我的 | `pages/settings/settings` | 手机授权、Cloud 连接、开发版测试地址、帮助和旧版入口 |
| 设备详情 | `pages/power/power?computer=...` | 固定设备的状态、电源操作、Codex 控制入口与 LAN / 唤醒设置 |
| Codex 控制 | `pages/codex/codex?computer=...` | 固定设备的项目、聊天、队列、附件和审批 |
| 使用帮助 | `pages/help/help` | 连接、权限、电源和唤醒指引 |
| 独立局域网 / 旧版连接 | `pages/index/index` | 保留无需 Cloud 的独立电源控制和 v1 配对 |
| 旧 Cloud 入口 | `pages/cloud/cloud` | 保留旧链接的兼容跳转 |

旧 `?tab=home`、`?tab=devices` 和无页签链接进入“我的设备”；带 `computer` 时直接进入对应详情。`?tab=connect` 进入“我的”，`?tab=help` 打开帮助，`?tab=codex&computer=...` 继续直达目标控制页。原生页签通过 `switchTab` 打开，不携带查询参数；详情和控制页通过 `navigateTo` / `navigateBack` 保留正确的页面层级。

## 使用流程

1. 在 **我的** 扫描 Cloud 手机授权码。需要开发时开启手机的 **Codex Remote** 权限，电源权限单独授权。
2. 授权成功自动切到 **我的设备**，显示同一 Cloud 当前授权的 Windows 电脑。
3. 点击设备卡片，进入对应的 **设备详情**。详情不提供切换电脑的下拉框。
4. 在详情执行电源操作，或打开 **Codex 控制**，继续该设备的项目和聊天。控制页显示当前设备，不提供其他设备的切换入口。
5. 从 Codex 返回设备详情，再返回设备列表；更换设备在列表重新点击。

“我的”集中管理授权、开发版 Cloud 地址、帮助和独立局域网入口，不进入某台电脑的会话或电源页面。进入 Codex 内的文件、能力目录和外观设置仍使用原有内部返回规则。切到原生“我的”页签会按微信规则关闭二级页面，未发送草稿与附件不持久保存；同一控制页临时切后台后保留内存草稿，恢复时不自动重发任务。

Codex 沿用已有的自定义顶部导航，避让状态栏和微信胶囊；设备内的工作台顶部提供“返回设备详情”，聊天中的返回先回到工作台。菜单、搜索、文件与能力目录保持原有操作。

## 设备与授权边界

设备列表只展示当前手机授权中的 Windows 电脑，显示在线、离线、电源操作中或状态未知。缓存只保存设备标识、名称与最近选择，不缓存可操作状态。列表可见时每 10 秒更新；详情可见时每 5 秒检查电源状态，后台停止轮询，网络恢复和下拉刷新重新读取。

点击时将设备标识传入详情；详情再把同一标识传入 Codex。两个页面都保留明确的目标设备，返回、状态刷新或其他页面更新最近选择不会改变它。目标不在当前授权列表时关闭旧控制状态并提示“无法访问这台设备”，即使还有其他电脑也不会自动选择第一台。页面栈中只复用同一目标的已有页面。

开发、体验和正式环境的授权、电脑缓存、LAN 配对与唤醒设置沿用原有存储规则。换 Cloud、换手机身份或移除授权时，迟到响应不能覆盖新列表或开放旧控制。Cloud 访问失败保留设备名并将状态标为未知；已保存的 LAN 配对仍按原有独立授权规则使用。Codex 继续使用 Cloud HTTPS / WSS，独立局域网旧版入口不提供 Codex。

## 验证与真机检查

导航检查覆盖两页签与默认首页、旧路径、原生页签跳转、页面栈、卡片传参、目标删除、扫码回流、环境身份隔离与迟到响应。现有 LAN / Cloud / Codex 检查继续验证电源路由、长期授权、回执、草稿和审批。微信 WCC / WCSC 编译与 320 / 390 / 430px 渲染覆盖设备列表、详情、我的、Codex、帮助、浅深色与键盘布局。

编译后的 DOM 适配渲染与导航接口模拟不等同于微信真机验收。导入 `windows/out/CodexDock-mini-program-3.5.0.zip` 后，应人工确认底部两个页签、设备名称与状态、详情和 Codex 的目标一致、连续返回、扫码回流以及 Wi-Fi / 5G 恢复。实际任务、附件返回和电源操作仍由人工验收。
