# Cloud 1.7.0 界面指南

控制台按使用目的分为七个入口。日常操作从总览开始，详细配置放在对应管理页。v1.7 的部署和使用边界见 [升级说明](upgrade-v1.7.md)。

| 入口 | 用途 |
|---|---|
| 总览 | 实时状态、分组与批量操作；开机反馈、远程桌面和复制 IP |
| 我的电脑 | 查看版本、连接与局域网信息，配置唤醒；展开“名称与管理”改名或移除电脑 |
| 远程唤醒 | 连接、管理唤醒网关，为电脑关联或解除网关，查看自动配置进度 |
| 手机授权 | 选择允许的操作，为微信小程序生成一次性二维码，逐部撤销 |
| 计划任务 | 按北京时间创建每日或每周电源操作，暂停、启用和删除 |
| 活动记录 | 查看目标电脑和完整时间，筛选事件并分页查看历史 |
| 设置 | Passkey、恢复码、离线微信通知、Cloud 地址和版本 |

## 连接与控制

1. 在 Windows 应用中打开 Cloud 连接。网页点击“连接电脑”，复制 Cloud 地址到 Windows，发起连接后取得短配对码。
2. 在同一个网页填写短码，核对设备名称并允许连接。旧 Windows 的长码入口位于页面下方折叠区；原 `/devices/enroll` 链接仍会跳转到新入口。
3. 电脑上线后回到总览。状态每 5 秒检查并推送变化，无需重复点击“查看状态”。开机要求唤醒可用且电脑不在电源切换中，其余电源动作要求在线且存在控制路径。
4. 开机直接发送唤醒指令并在按钮旁等待上线反馈；其他电源操作会先显示包含设备名称的确认框，取消或按 Escape 不会发送指令。确认后显示处理结果，也可进入活动记录追踪。
5. 需要远程开机时，从电脑详情进入“配置唤醒”，网页会预选当前电脑。保持电脑与网关在线并位于同一局域网，选择网关后等待自动配置。

网关管理和电脑管理分别位于对应页面，改名或移除后返回原类别。备用控制折叠在网关高级选项中，选择电脑时会带入已保存的备用控制开关。解除关联前也会确认影响。

## 手机与账户

“手机授权”先填写名称，再生成二维码；二维码页面突出扫码步骤与有效时间，已授权手机在下方独立管理。一次扫码长期有效，主动撤销后需重新扫码。旧客户端信息收在折叠区中。

原“系统”内容并入“设置”的服务信息，原 `/system` 链接跳转到 `/settings#service`。登录页、初始化、恢复码、旧版配对与操作结果使用统一的视觉样式。

## 验证

- Cloud 119 项测试与状态同步脚本通过，覆盖身份、权限、旧协议、管理后的跳转与设备分类。
- Chromium 在 1440、390、320 像素宽度检查七个主要页面和登录页，无页面横向溢出；无设备、无网关、无手机等空状态有对应指引。
- 使用隔离设备验证电源确认取消与单次提交、网关改名和解除关联、二维码生成、无效配对码、网络失败禁用操作及恢复同步。
- 视觉截图和测试凭据仅保存在本机临时目录，不纳入源码。此轮 UI 验证不等同于物理电源动作验收。

2026-10-01（北京时间）已部署正式 Cloud `1.6.0`，原账户、电脑、网关和手机授权保留。公网七个页面在桌面与手机宽度通过渲染检查，真实电脑和网关在线，HTTPS 证书正常；验证没有发送真实电源指令。刷新 Cloud 页面即可使用，部署过程及回滚边界见 [部署记录](cloud-deployment.md#控制台界面更新2026-10-01)。
