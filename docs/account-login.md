# 三端统一账号与自动连接

Cloud / Web / Windows `1.23.2`、微信小程序 `3.6.0` 起，网页、电脑和手机支持同一账号密码登录。本轮覆盖这三端，网关沿用原协议与版本。

## 使用流程

三端必须使用**同一个 Cloud 地址与账号**。不同 Cloud 的账号和设备相互独立。

1. 新用户在已开放注册的 Cloud 网页或小程序创建账号。账号为 3 至 40 位字母、数字、点、下划线或短横线，不区分大小写；密码为 12 至 256 个字符。
2. 已有 Passkey 用户先在 Cloud 网页登录，在「设置 → 统一账号」设置密码。原账号、Passkey、恢复码、电脑和手机授权继续保留。部署配置中的管理员密码也可直接用于三端登录。
3. Windows「远程连接」填写相同 Cloud 地址、账号与密码，点击「登录并连接电脑」。这台电脑自动加入账号，网页与手机无需再批准短码。
4. 小程序「我的 / 连接与设置」填写相同地址、账号与密码。登录后自动读取账号下的电脑，选择电脑即可控制，无需扫码。已有扫码手机可直接在账号表单中登录，使用原凭据保留手机编号。
5. Codex Remote 仍需电脑端启用功能、授权项目，并连接已登录的原 Codex 窗口。账号登录的手机具备本人设备的电源与 Codex 权限；电脑端的项目授权继续独立生效。

电脑在线时，网页或手机通过 Cloud Direct 控制它。网关不参与上述登录和在线控制；电脑关机后的远程唤醒仍需要可用的唤醒通道。没有 Cloud 网络时，已有局域网直连仍可使用原本地授权，同账号登录不会把局域网密钥上传 Cloud。

## 账号与连接管理

- 每个账号只看到自己的电脑、手机客户端和活动。手机凭据不能冒充 Windows，Windows 凭据不能用来访问手机或网页控制接口。
- Windows 使用 DPAPI 加密保存本机凭据与随机连接标识；小程序仅保存独立手机客户端凭据与随机连接标识。两端不保存登录密码，Cloud 仅保存密码派生结果和随机凭据哈希。
- 同一安装的重复登录、安全重试以及旧配对转入账号时保留原电脑编号。提供旧编号必须同时证明持有旧刷新凭据，不能仅凭编号转移归属；已被移除的设备不会恢复旧授权。
- 切换账号或 Cloud 前先退出。电脑退出会断开并撤销该电脑的云端连接；手机退出只撤销本手机。原网页仍可逐个撤销手机或移除电脑。
- 「设置 → 统一账号」支持修改密码。需验证当前密码，也可在使用 Passkey / 恢复码重新登录后的五分钟内设置。修改后撤销其他浏览器会话及通过账号登录的原生连接，重新登录同一安装仍保留有效电脑编号；既有扫码配对保持兼容。由部署配置管理的管理员密码通过配置修改，同样撤销通过账号建立的会话。
- 没有 Passkey 或恢复码的普通账号目前不提供邮件或短信找回。建议在网页登录后添加备用 Passkey 并保存恢复码。

## 部署与数据保留

数据库新增迁移 `0010_accounts`，只为原用户、浏览器会话补充字段并创建账号连接映射表，不替换原数据库。已有用户默认不启用新的数据库密码入口，避免把初始化时的随机密码当作登录密码。原部署密码入口、Passkey、恢复码、身份、配对与配置继续兼容。

正式部署默认不开放注册。需要让用户自行创建账号时，在私有 `.env` 中设置 `LANPOWER_ALLOW_REGISTRATION=true` 并重建 Cloud 容器；关闭注册不影响已存在账号登录。本机独立 Docker 开发环境显式开放注册，用于体验和验证。新 Cloud 仍需先完成服务器初始化，注册接口不能接管初始化中的管理员账号。

升级前使用 SQLite backup API 一致备份数据库，先在隔离副本运行迁移，并保留原数据卷、私有配置和证书。不要用本机测试数据库替换远程数据库。Windows 就地升级保留现有安装目录、DPAPI 凭据、本地授权与用户设置。三个组件都需升级到支持账号登录的版本；旧 Cloud 返回明确升级提示，失败登录不会删除旧连接。

## 接口与验证边界

网页使用安全 Cookie 与 CSRF；原生端使用 `POST /api/v2/account/register` 与 `POST /api/v2/account/login`。登录请求必须说明 `windows` 或 `mobile` 类型，并携带随机安装连接标识；不接受网关类型。服务端独立签发 Windows / 手机凭据，沿用已有续期与撤销接口。密码登录按来源与账号限流，错误不会泄露密码或令牌。

微信安全随机数 API 用于手机连接标识，基础库不支持时提示升级微信或使用原扫码方式。参见 [微信接口类型声明](https://github.com/wechat-miniprogram/api-typings)；不使用普通伪随机数替代登录标识。

本轮自动验证覆盖三端同账号、模拟在线电脑控制、不同账号隔离、角色隔离、并发/丢失响应后的重复登录、旧凭据转入账号、密码修改与撤销、浏览器来源、CSRF、注册关闭、初始化保护、开发/体验/正式环境和账号切换后的迟到响应。微信编译及浏览器布局属于自动验证，真机微信登录、5G、实体电脑电源与唤醒继续由人工验收。
