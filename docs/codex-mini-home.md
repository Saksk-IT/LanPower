# 微信小程序 Codex 首页

小程序 `3.2.2` 参照 ChatGPT iOS 的 Codex 列表和菜单重做首页。`3.4.2` 将页面工具栏作为自定义顶部导航，去掉重复的「Codex Remote」标题栏，保留微信胶囊和项目底部导航，配合既有 Windows / Cloud 接口使用。状态栏与胶囊适配见 [顶部导航](codex-mini-navigation.md)。

- 顶部为圆形菜单与搜索按钮、居中的 Codex 标题和电脑选择。标题也能打开菜单。全部和独立聊天筛选均作用于当前选中电脑；选择另一台电脑后重新读取其项目、会话和实际用量。
- 默认先显示最近，再显示项目。最近包含项目内会话与独立聊天，按电脑返回的更新时间倒序；显示方式不修改会话时间。默认展示六条，点击“查看全部最近会话”可逐页查看，未加载的数据仍有“读取更多聊天”入口。
- 项目采用文件夹图标与缩进列表。点击项目名展开或收起，右侧按钮新建该项目会话；长按项目名可以重命名、排序、收纳或浏览文件。会话保留长按与右侧菜单操作。
- 顶部弹出菜单可选择按项目、按时间倒序或优先级。优先级依次显示待回复、运行中、置顶、其他会话，同一优先级仍按更新时间排序。“优先显示最近”决定项目与最近区域的先后顺序。
- 首页显示方式按小程序环境与电脑分别记住。项目收纳、展开、置顶和显示名沿用电脑端整理状态；首页列表模式不改变网页的独立聊天排序偏好。
- 管理菜单连接已有归档/恢复、添加连接、设置、技能与应用、自动化入口。剩余用量直接读取电脑的原生额度窗口，没有数据或连接断开时显示说明；不会填入参考图中的示例百分比。
- 底部“向 Codex 提问”打开既有新建会话流程，选择项目或独立聊天后进入对话。电脑未就绪时新建入口禁用，重连与已配置的唤醒入口保留。

验证使用微信 WXML/WXSS 编译器和浏览器适配器，在 320、390、430 像素检查浅色/深色首页和弹出菜单、标题截断、独立聊天筛选、搜索与清除、优先级、显示偏好、完整分页、项目操作、新建入口、断线状态及已有聊天/审批/键盘/图片功能。首页数据排序、收纳、原生额度与既有状态共 39 项测试通过。此验证属于本机编译与模拟交互，微信真机和公网 5G 仍需人工验收。

本轮不上传微信平台、不推送远程仓库、不部署正式云服务器。导入 `mini_program` 目录后重新编译，已有手机授权继续沿用。

## 3.6.1 自动加载修复（2026-10-06）

修复首次进入 Codex 页面时停留在“正在连接”、最近聊天和项目为空，必须打开顶部菜单并切换“优先级 / 按项目”才显示内容的问题；后台返回时也自动更新连接状态、聊天列表和当前对话。

页面初始化会排队一次刷新，随后 `onShow` 清理计时器时只取消回调，没有清空 `paintTimer`。后续连接和列表结果已到达控制器，但 `schedulePaint` 仍认为刷新在排队，持续跳过页面更新。切换排序直接调用 `paint`，才让内容重新显示。现在清理时同步清空刷新句柄，使后续数据变化可以重新排队刷新。

`node tests/test_mini_program_codex.js` 的回归检查在旧代码下复现首次列表不能自动显示，修复后通过。检查直接等待页面数据自动变化，不手动重画页面或切换排序，并覆盖后台返回后的聊天名称更新、草稿自动显示与任务不重发；首页、控制器状态及设备导航共 49 项检查通过。

本次仅更新小程序到 `3.6.1`，继续兼容 Windows / Cloud / Web `1.23.2` 和协议 `2`。导入包为 `windows/out/CodexDock-mini-program-3.6.1.zip`，从本次已提交的公开小程序源码生成，使用占位 AppID。自动接口与页面生命周期检查不等同于微信真机或 5G 验收；导入完整目录并重新编译后，在微信中检查直接进入 Codex、返回页面和原排序偏好。
