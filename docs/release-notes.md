- 统一浅色与青绿色视觉、图标、卡片、表单和状态提示，适配桌面侧栏与手机导航。登录、连接引导、授权及结果页使用同一套设计。
- 连接设备整合为填写 Cloud 地址、获取短码、核对授权三步；旧版长码保留折叠入口。空列表给出下一步，手机二维码与已授权手机分开管理。

- 本轮仅更新 Cloud；Windows `1.5.0`、微信小程序 `2.0.2`、Wake Gateway `2.1.0` 保持原版本，无数据库结构变更。未同步远程仓库或发布 Release。详见 [界面指南](cloud-ui.md) 与 [部署记录](cloud-deployment.md#控制台界面更新2026-10-01)。

## Cloud 1.5.1 / 小程序 2.0.2：手机长期授权

- 手机扫码一次后长期有效；Access Token 仍为 15 分钟，手机通过独立续期接口自动更新，断网、响应丢失或退出微信后可重试。
- 网络故障、Cloud 暂时不可用和本地保存失败不再误报“需要重新扫码”。旧 Cloud 会显示更新提示并保留授权。
- 数据库迁移保留手机身份和凭据，将未撤销授权改为长期；主动撤销仍立即生效，已作废或丢失的旧密钥不会恢复。
- 先升级 Cloud，再更新小程序。旧版已消费刷新凭据但丢失新凭据的手机可能仍需最后扫码一次，详见 [升级说明](mini-program-v2.md#长期授权升级)。
- Cloud 117 项测试、小程序两套回归、Cloud 状态脚本与微信模板编译通过。正式 Cloud 已保留数据升级至 `1.5.1`，公网续期重试和撤销隔离通过；本机小程序源码已更新，开发者工具 CLI 超时，手机仍需重新预览或上传新版。本轮未推送远程仓库或发布 Release。

## LanPower 1.5.0：自动配置远程唤醒

Windows 与 Cloud 更新至 `1.5.0`，Wake Gateway 更新至 `2.1.0`，小程序更新至 `2.0.1` 并补充自动配置帮助。协议版本保持兼容。

- Windows 点击“配置远程唤醒”后，网页自动选中本机；选择网关即可同步配置，无需手填电脑编号、MAC 或广播地址。
- 网关直接从局域网读取唤醒信息并持久保存，电脑离线或进程重启后保留；解除关联后自动移除。手工配置继续优先，备用电源控制仍需单独配置。
- 页面展示配置进度及可操作的失败提示。短效只读票据无法执行电源操作，MAC、广播地址和 LAN 控制密钥不上传 Cloud。

- Windows 提供普通用户桌面端、LocalSystem 服务和安装包，保留旧 LAN API。
- 在线电脑直接连接 Cloud；浏览器或小程序可查看状态、睡眠、休眠、重启和关机，无需网关。
- Cloud 提供 Passkey、恢复码、短码设备批准、独立手机授权、设备移除与审计。
- 可选 Wake Gateway 支持多电脑唤醒和显式启用的备用 LAN 控制。
- 小程序采用局域网优先与 Cloud 回退，并按电脑分别保存本地配对。
- Docker Compose 支持 Caddy 自动 HTTPS、持久化数据及旧协议兼容。
- Windows 支持网络监控、Wi-Fi/离线安装、连接管理、凭据恢复和手动更新检查。

下载 `LanPowerSetup-x64.exe` 安装 Windows 应用。便携分发包需要管理员将服务安装到受保护的目录。网关二进制目标为 Linux ARM64。`SHA256SUMS.txt` 可校验三个发布文件；Cloud 镜像按产品版本及源码提交标记。

自动配置已在指定 Cloud、Windows 和真实路由器验证，包含保留原数据与配对的升级，以及自动配置持久化和网关进程恢复。本轮没有执行物理电源动作，多电脑硬件及整机重启仍待验收，详见 [自动配置验收](wake-gateway.md#自动配置验收2026-09-30)。此文件为发布说明草稿，当前仅本地构建与部署，未正式发布。
