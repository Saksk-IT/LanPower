# LanPower v1.6.1

整合 Windows 桌面应用、Cloud Direct、Cloud 控制台、手机长期授权和自动配置远程唤醒，并提供完整分发资源。

| 组件 | 版本 |
|---|---|
| Windows / Cloud | `1.6.1` |
| 微信小程序 | `2.0.3` |
| Wake Gateway | `2.1.1` |

## 主要更新

- Windows 提供桌面界面、托盘、二维码配对和 LocalSystem 服务；改进安装失败诊断、健康检查及快捷方式创建。保留原有 LAN API 和安装配置。
- 在线电脑通过 Cloud Direct 接收枚举电源指令，无需网关；状态同步可处理断网、恢复、旧响应和电源过渡。
- Cloud 控制台按总览、我的电脑、远程唤醒、手机授权、活动记录和设置组织，适配桌面和手机，提供连接引导与操作确认。
- 小程序采用 LAN 优先和 Cloud 回退，按电脑保存局域网配对；扫码授权长期有效，短期访问凭据自动续期，断网或响应丢失可重试，主动撤销立即生效。
- Windows 发起远程唤醒配置后，在网页选择网关即可保存唤醒信息，无需手填 MAC、广播地址或重启网关。一个网关支持多台电脑，LAN 控制密钥不上 Cloud。
- 发布脚本检查版本一致性、个人配置及提交邮箱，小程序从已提交的公开源码打包；Windows 便携包按白名单生成并逐项校验。
- Windows 心跳、配对与桌面状态统一读取程序构建版本；演练服务使用按进程隔离的通信名称，可在已安装服务的电脑上安全验证。

## 下载与升级

Release 提供 `LanPowerSetup-x64.exe`、`LanPower-portable-x64.zip`、`lanpower-gateway-linux-arm64`、`LanPower-mini-program.zip` 和 `SHA256SUMS.txt`。Cloud 镜像为 `ghcr.io/saksk-it/lanpower-cloud:1.6.1`，并提供对应的 `sha-<源码提交>` 标签；完整源码通过本版本的 Source code 下载。

建议使用相同类型的 Windows 安装器升级；便携包也需要管理员安装服务。Cloud 升级前备份数据，保留原有数据库、配置和凭据；先升级 Cloud，再重新预览或上传小程序。旧版手机授权已丢失或已撤销时需要重新扫码。详见仓库 `docs/mini-program-v2.md` 和 `docs/releasing.md`。

## 验证边界

发布流程先运行 Windows 构建、单元与 IPC 测试、安装器流程测试、Cloud 119 项测试、小程序与状态脚本回归、Linux Gateway 测试和静态构建，再校验实际安装包、便携组件和 Cloud 镜像。发布源码和产物不会自动更新用户现有生产服务，也不会上传到微信后台。

已有实际部署验证覆盖安装迁移、Passkey、Cloud/Windows/网关在线状态及自动唤醒配置。历史 v1.1.2 已完成 iPhone 5G 睡眠和唤醒实测；新版全部物理电源动作、多电脑硬件、路由器整机重启及微信真机网络切换仍待逐项验收。
