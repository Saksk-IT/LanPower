# Codex Remote 首批六项修复与验收

2026-10-04，依据 [深度审查报告](codex-remote-deep-review.md) 修复 R1–R6。实施基线为 Windows / Cloud / Web `1.17.0` 与小程序 `3.0.0`；本次版本为 `1.18.0` / `3.0.1`。原报告保留审查时的快照和证据，不把当时的过渡状态当作当前版本状态。

## 修复结果

| 问题 | 新行为 | 对应回归 |
| --- | --- | --- |
| R1 大项引用失效 | 正文缓存与发布引用分离；正文被淘汰后，根据原生会话、轮次和条目重新定位，核对哈希后继续分段。保留 64 MiB 正文预算，最多 4096 个引用、10 分钟空闲租约。客户端按稳定条目标识限制自动恢复次数，失败后留下手动重试入口 | C# 和实际 Renderer 同页两个 17 MiB 项完整恢复；背景缓存压力、取消、过期、内容变化；浏览器断线续读、过期恢复、迟到结果隔离 |
| R2 旧页分支/回退 | 客户端发送目标 `turnId` 与读取时的尾轮 `expectedTailTurnId`。电脑端全历史定位，在操作前再核对尾轮和活动状态；分支使用原生 `lastTurnId`，回退由电脑计算全局轮数。旧 Host 缺少能力时提示更新。失败保留阅读窗口，回退说明已有文件修改保留 | 实际 Renderer 对 180 轮开头、中间和末尾执行分支/回退，新增尾轮时拒绝写操作；浏览器开头窗口提交稳定编号，拒绝后仍显示第一轮；小程序相同契约 |
| R3 输入与错误归属 | 清空草稿前校验最终文字及文件引用前缀、4 张图片/合计上限和 8 项技能；文字按 Unicode 标量计数，拒绝无效代理对。Cloud 参数校验失败以原请求编号返回 `-32602` 和 `data.notSent:true`，不派发到电脑。33 条队列不发送重排 | ASCII/中文/emoji 的 16000 与 16001 边界、附件前缀、多图、技能/队列限制；两个页面使用相同编号时的未发送回执；浏览器立即反馈并保留草稿，不进入待确认 |
| R4 工具类型展示 | MCP、网页搜索、动态工具、协作任务、上下文整理与审查条目显示对象、公开输入/结果/错误及状态；未知类型保留安全详情和更新提示。传输与客户端递归清理隐藏/加密推理，上下文整理只显示公开提示 | 各类型进行中/成功/失败映射、停止状态、未知类型及嵌套推理过滤；浏览器六类卡片与公开详情 |
| R5 聊天库完整性 | 目标电脑读取授权范围内的活跃/归档元数据，按查询分页并独立返回置顶；核验已加载编号，保留仅未出现在首屏的旧页条目。归档、恢复、新会话和重命名事件触发刷新，定期核验补偿遗漏。嵌套项目统一最长规范化根目录；保留组织状态并显示当前阅读对象 | 180 条元数据、首屏外搜索和置顶、归档/恢复、旧页保留、游标变化和嵌套目录；浏览器及小程序全量目录契约 |
| R6 图片生命周期 | 淘汰/重连清理组件地址，点击重新解析；放大图片有读取引用，关闭后释放。提供读取状态、失败重试与原图下载。小 PNG/GIF/WebP 保留原编码；超限动画明确拒绝，PNG 缩图保留透明格式。预览为极小图和下载按钮保留可点击空间 | 实际 Vue 组件 33 张以上淘汰后点击恢复、预览期间 40 张压力；10 张 7 MiB 图片触发字节预算；重连、原图下载字节一致；输入透明/动画格式保留与超限拒绝 |

完整目录仅缓存元数据，最多 100000 条；Cloud 不建立正文索引。快照修订号变化后拒绝旧游标，避免混合不同查询结果。收纳、别名、展开和置顶仍存于目标电脑的既有配置。
