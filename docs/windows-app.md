# Windows 应用

Windows 应用由普通用户权限的 WPF 桌面端和 LocalSystem 服务组成，提供应用图标、侧边导航、连接状态显示和系统托盘。服务提供兼容旧版的 LAN API，同时可选连接 Cloud。关闭桌面窗口默认收起到托盘，后台服务继续运行。

## 安装与首次使用

新版安装包目前需从源码构建，步骤见 [Windows 构建说明](../windows/README.md)。输出 `windows/out/LanPowerSetup-x64.exe`，无需终端用户另装 .NET。安装程序请求管理员权限，设置服务、LAN 防火墙、受保护的数据目录和快捷方式。

安装后打开 LanPower，在“设备总览”检查局域网地址与连接状态。点击“连接我的手机”或左侧“手机配对”，让手机连接同一局域网，再点击“显示配对二维码”，用 LanPower 小程序扫描。局域网控制不依赖 Cloud 或路由器程序。

二维码直接显示在应用内；可手动收起，切换页面、隐藏窗口或两分钟后自动收起。自动收起只隐藏二维码，不会撤销已配对手机的权限。旧服务尚不支持应用内二维码时，可使用“打开浏览器配对页”，或安装新版应用。二维码包含配对凭据，请勿分享。

安装器优先选择有线物理网卡，也支持 Wi-Fi。暂时离线时仍可安装服务和桌面端；联网后再检测和选择网卡。Wi-Fi 可用于 LAN/Cloud 控制，能否无线唤醒取决于硬件、驱动和电源状态，需单独实测。

## 安装失败排查

若 Setup 末尾报告“LanPower Service 安装失败”，文件可能已经复制；桌面存在旧快捷方式不能证明服务已安装成功。当前安装器在服务检查通过后才新建快捷方式和允许启动；失败会显示“安装未完成”，并返回非零退出码。

保留弹窗中的失败阶段、PowerShell 返回码、Win32 错误码和服务退出码。以管理员权限读取 `%ProgramData%\LanPower\logs\install.log`；若文件不存在，保留弹窗并查看安装进程 `%TEMP%` 下最新的 `Setup Log *.txt`。安装脚本启动被系统阻止时，可能只能取得 PowerShell 返回码。

按提示的阶段继续检查：

- “读取原配对配置”：先备份现有配置，再检查其完整性，不要删除配对数据反复尝试。
- “设置 Windows 防火墙”：检查 Windows 防火墙服务、组织策略和安全软件的拦截记录。
- “启动 Windows 服务”或“验证本机服务接口”：检查事件查看器中同一时间的 Service Control Manager、.NET Runtime 或 Application Error 记录，以及服务日志和 `48211` 端口占用。
- 服务已运行但双击无窗口：另查桌面程序的应用错误和安全软件记录；服务连接失败本身应在桌面显示状态未知，不能仅凭服务错误推断窗口无法打开的原因。

安装检查使用原配对密钥直连本机，避免安装用户代理干扰，不跟随 HTTP 重定向。失败清理会尝试移除本轮新建的服务并恢复旧版任务；已经复制的文件、已有服务配置和防火墙变更不承诺完整回滚，原配对数据保留。排查时提供错误阶段、错误码和相关事件即可，不要提供 `config.json`、Cloud 凭据或配对二维码。

2026-09-30 用户已在本机 Windows 沙盒完成两次安装且均成功。部分完整版 Windows 11 的故障仍需以目标电脑的新诊断确认，尚未确认共同根因。

## 连接 Cloud

在“远程连接”输入自己的 HTTPS Cloud 地址，点击“连接 Cloud”。在 Cloud 网页输入电脑显示的短码，核对电脑名称后批准。服务保存独立设备凭据，桌面端不会读取 Refresh Token。每次启动会恢复已保存的 Cloud 地址。

桌面端自动刷新状态，底栏显示刷新时间与间隔，也可随时点击“刷新状态”。总览分别显示局域网、Cloud 和唤醒网关状态，以及在家控制、在外控制、远程唤醒三条路径：

- “未配置”表示可以继续只用局域网。
- “需要重新连接”表示应检查 Cloud 中的设备状态并重新配对。
- Wake Gateway “未配置”时，在线远程控制仍可用。
- “已连接，远程唤醒可用”表示 Cloud 找到了在线且配置匹配的网关。
- “已连接，待配置电脑”表示网关尚未完成自动同步；详细提示会说明正在配置、等待电脑上线、需要升级或局域网不可达。

需要远程开机时，点击总览的“配置远程唤醒”，或在“远程连接”中点击“选择唤醒网关”。浏览器打开 Cloud 并预选当前电脑，登录后选择同一局域网内的网关，点击“使用这个网关”。保持两端在线，通常约 30 秒后显示“远程唤醒可用”。无需填写设备编号、MAC 或广播地址，也无需重启网关。已有网页关联在三端升级后会自动同步；路由器上的网关程序仍需先安装并完成首次注册。

系统允许网卡唤醒不代表固件、休眠和关机状态均支持 WOL；需要逐项实测。

无法联系后台服务时，界面显示“状态未知”，清除旧地址和旧在线状态，暂停 Cloud 操作；服务恢复后自动重新显示状态。

“停止等待”会取消服务内的本次配对。“断开 Cloud”会清除本机云端连接信息并停止领取命令。能够联系 Cloud 且授权仍有效时，会同步移除原设备；否则按提示在 Cloud 控制台移除原记录。已接收的电源动作无法撤回，局域网配对继续保留。

凭据刷新遇到响应丢失或进程中断时，服务提示重新连接，不会反复使用旧刷新凭据。只在最终写盘失败时，会保留新响应并重试本地保存；若此时重启服务，则需要重新配对。

## 页面与托盘

| 页面 | 可视化操作与显示 |
| --- | --- |
| 设备总览 | 本机连接状态、控制路径、IP、MAC、WOL 与手机配对入口 |
| 手机配对 | 应用内二维码、收起倒计时、浏览器配对入口 |
| 远程连接 | Cloud 地址、短码批准进度、断开连接、唤醒网关状态 |
| 网络设置 | 物理网卡选择、地址自动更新、重新检测、Windows 网络设置 |
| 日志诊断 | 服务日志、刷新与复制、Windows 服务管理入口 |
| 应用设置 | 关闭到托盘、版本查询、更新代理偏好 |

双击托盘图标恢复窗口，右键菜单可直接进入手机配对、日志诊断或“退出界面”。再次启动应用会恢复已有窗口，不重复创建托盘图标。在“应用设置”关闭“关闭窗口时，收起到系统托盘”后，关闭窗口即退出界面。两种方式均不停止后台服务。

窗口和更新偏好保存在当前用户的 `%LOCALAPPDATA%\LanPower\desktop-settings.json`，不会影响其他 Windows 用户。

## 数据与维护

数据保存在 `C:\ProgramData\LanPower\`：`config.json` 为局域网配置；`credentials.dat` 为 DPAPI Machine Scope 加密的 Cloud 凭据；`cloud-replay.jsonl` 为命令记录；`logs/` 为服务日志。不要复制 Cloud 凭据到其他电脑，也不要删除命令记录后立即重试尚未过期的电源指令。

“日志诊断”通过命名管道读取服务日志。桌面端不直接执行电源、服务或防火墙管理。卸载保留 ProgramData，以便重装继续使用原配对；可通过桌面“断开 Cloud”或网页“我的设备”移除云端授权。

在“网络设置”选择物理网卡。开启自动更新后，服务每 25 秒检测所选网卡，地址变化时同步更新配对地址和防火墙范围；不会自动换到另一张网卡。旧固定配置可继续使用，也可在此启用自动更新。变更地址或网卡后，让手机重新扫码确认。网卡离线或更新失败时，局域网远端访问暂停，本机页面与 Cloud 不受此设置阻断。

在“应用设置”点击“检查更新”，读取本项目的公开正式版本，并打开下载页供用户安装。只检查正式发布，不自动下载安装。系统代理连接失败时，可关闭“更新检查使用系统代理”重试，选择会保存到当前用户的桌面偏好文件。桌面版本和后台服务版本分别显示，便于识别只更新了界面的情况。

自动验证覆盖地址改变、网卡断开与恢复、固定模式、私有网段边界及写盘/防火墙失败时拒绝访问。目标 Windows 已通过管理员首次安装、旧 Python 到 Setup 迁移、便携包安装及卸载重装检查；卸载保留原配置、加密 Cloud 凭据、命令记录和日志，重装后 LAN 配对与 Cloud 连接恢复。真实网卡变化与防火墙随地址变化仍需实机验收。详细证据见 [Windows 验证记录](../windows/README.md#验证边界)。
