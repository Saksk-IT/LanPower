# Windows 应用

新 Windows 应用由普通用户权限的桌面端和 LocalSystem 服务组成。服务提供兼容旧版的 LAN API，同时可选连接 Cloud。关闭桌面窗口不会停止服务。

## 安装与首次使用

新版安装包目前需从源码构建，步骤见 [Windows 构建说明](../windows/README.md)。输出 `windows/out/LanPowerSetup-x64.exe`，无需终端用户另装 .NET。安装程序请求管理员权限，设置服务、LAN 防火墙、受保护的数据目录和快捷方式。

安装后打开 LanPower，检查局域网地址和网卡。在手机连接同一局域网后点击“打开手机配对”，用小程序扫描本机配对页。可点击“跳过 Cloud，开始使用”；局域网控制不依赖 Cloud 或路由器程序。

当前安装器检测已连接的有线物理网卡。只使用 Wi-Fi 的电脑尚未完成此安装路径适配；不要把有线网卡检查通过等同于 WOL 硬件验收。

## 连接 Cloud

输入自己的 HTTPS Cloud 地址，点击“连接 Cloud”。在 Cloud 网页输入电脑显示的短码，核对电脑名称后批准。服务保存独立设备凭据，桌面端不会读取 Refresh Token。每次启动会恢复已保存的 Cloud 地址。

桌面端每 20 秒刷新状态：

- “未配置”表示可以继续只用局域网。
- “需要重新连接”表示应检查 Cloud 中的设备状态并重新配对。
- Wake Gateway “未配置”时，在线远程控制仍可用。
- “已连接，远程唤醒可用”表示 Cloud 找到了在线且配置匹配的网关。
- “已连接，待配置电脑”表示需同时补全网关本地电脑配置与 Cloud 关联。

系统允许网卡唤醒不代表固件、休眠和关机状态均支持 WOL；需要逐项实测。

## 数据与维护

数据保存在 `C:\ProgramData\LanPower\`：`config.json` 为局域网配置；`credentials.dat` 为 DPAPI Machine Scope 加密的 Cloud 凭据；`cloud-replay.jsonl` 为命令记录；`logs/` 为服务日志。不要复制 Cloud 凭据到其他电脑，也不要删除命令记录后立即重试尚未过期的电源指令。

“查看日志”通过命名管道读取服务日志。桌面端不直接执行电源、服务或防火墙管理。卸载保留 ProgramData，以便重装继续使用原配对；移除 Cloud 设备请在网页“我的设备”中操作。

IP 改变时，目前会显示地址变化或网络未连接。可先在路由器为电脑保留地址；需要更新网段时重新运行安装器，并重新确认配对地址。自动网络修复、桌面更新检查和高级配置仍在补齐中。
