# 安全边界

## 网络

- Windows LAN API 固定为局域网入口，默认端口 `48211`；服务校验来源网段及配对凭据，配对页仅允许本机访问。
- LAN 自动更新只跟随选定物理网卡并限定私有 IPv4 网段；防火墙限制本机地址、来源网段、服务程序和端口。配置或规则更新失败时，应用拒绝远端 LAN 请求。本机配对页仍可使用。
- Windows Cloud Agent 和 Gateway 只发起出站 HTTPS，不开放公网控制端口，不跟随携带凭据的 HTTP 重定向。
- Cloud 公网入口为 HTTPS；Docker 应用端口 `8765` 仅发布至回环。路由器 SSH 只用于可信 LAN 管理，不发布到 WAN。
- Cloud 故障不影响 LAN；网关故障不影响在线 Windows Cloud Direct；没有小程序时浏览器仍可控制。

## 身份与数据

- 管理员、设备和手机分开授权；资源按 `owner_id` 归属检查。浏览器和手机只能控制本账户的电脑。
- 设备和客户端随机 Token、恢复码只在 Cloud 数据库保存哈希。Windows 本地 Cloud 凭据由 DPAPI Machine Scope 加密并配合目录 ACL 保护。
- 网关凭据和执行记录只保存在本地私有文件；Cloud 不接收 Windows LAN Token。MAC、广播地址和备用 LAN 凭据由网关本地决定。
- 日志不输出授权头、Access/Refresh Token、LAN Token、完整设备码、恢复码或私钥。分享日志前也应检查是否含自定义设备名和地址等个人信息。
- Windows 和网关在刷新前持久记录状态，刷新结果不确定时要求重新注册；只在新响应写盘失败时重试本地保存，不重复已发送的刷新请求。设备的自撤销入口只接受设备自身授权，不接受任意目标编号。
- 新版小程序使用每手机独立的长期授权换取 15 分钟访问凭据，授权只在手机本地保存原文、Cloud 保存哈希。续期不消耗长期凭据，响应丢失和重启可重试；手机或管理员撤销后立即拒绝续期和访问。旧手机轮换接口保留重用撤销规则，升级不会恢复已作废的旧凭据。
- 已知凭据失效时持久记录授权失败，并合并重复请求；记录仅含既有数据库身份和事件，不保存提交的凭据或哈希，也不根据任意请求参数猜测账户归属。

## Codex Remote

- Windows 主动连接 Cloud WSS；app-server 只监听本机 stdio，登录状态使用当前 Windows 用户的 Codex Home。SYSTEM 服务不启动 Codex，也不读取 OpenAI 登录文件。用户 Host 检查管道服务端 PID 与真实 LanPowerService，管道拒绝网络/匿名身份，只允许 SYSTEM、管理员和交互用户。
- 浏览器必须携带现有会话 Cookie 与准确的同源 Origin；Agent 只接受 Windows 类型 Bearer 凭据。设备归属在连接和后续请求检查，连接每 5 秒复核身份；主动撤销设备立即关闭 Relay。URL 查询参数、跨站 Origin、手机/网关凭据和第二个控制页面会被拒绝。
- 本地授权默认关闭，只允许最多 32 个已在桌面端选择的项目根目录。Host 再次校验线程实际 cwd，拒绝 UNC、相对路径及路径上任一目录联接/符号链接；浏览器不能指定登录目录、配置、系统命令、任意文件接口或安全策略覆盖。
- Runtime 强制 `workspace-write` 与 `on-request`，固定任务的项目 cwd 和默认可写目录，默认关闭沙箱网络访问并排除临时目录额外写入。单次批准工具请求可能允许超出默认沙箱的操作，审批前应核对命令和目录。Windows 的具体隔离由本机 Codex 实现；这不是完整文件保密沙箱，也不承诺阻止 Codex 读取用户可读文件。只有可信用户才能使用远程开发账户和电脑登录会话。
- 命令和文件审批仅允许单次接受/拒绝/取消，不接受会话永久批准、策略修订或远端扩大文件系统权限。带 `grantRoot` 的额外文件目录只有精确匹配本机授权根目录才可接受。网络权限最多当前 turn；用户提问可回答，MCP 交互授权需在本机处理。未处理审批 5 分钟后拒绝，关闭本地授权结束 Runtime 和其工具进程。
- TLS 在 Cloud 终止，当前不是端到端加密。Cloud 只在有界内存中短暂看到任务、输出、Diff 和审批；这些内容不写数据库或日志。审计只记录已有账户/设备编号、事件类型、时间，PWA 缓存只保存公开静态文件。代理与运维不得启用 WebSocket 正文采样或转储。
- 单帧 1 MiB，Relay 每连接最多 32 帧/8 MiB 待发送，待回复和待审批各最多 64，浏览器请求 10 秒最多 120 条。超过限制时停止连接；不截断 RPC 后继续执行，不自动重发任务。Host 使用 Windows Job Object 管理 Runtime 子进程，崩溃/卸载退出时结束工具进程。

## 电源操作

Cloud、Windows 和网关都限制动作枚举；不支持任意 Shell、URL、脚本或请求体。命令绑定设备编号、有效期和随机标识，设备在执行前再次校验并保存接收记录。重复下发不会重复触发电源动作。

Web 和小程序的重启/关机等动作需要用户确认。状态查询不自动唤醒；结果未知时不通过另一条路径再执行。网关的备用控制需要 Cloud 与本地同时允许。

移除设备、撤销客户端或解除网关关联会阻止后续授权或命令领取。已经送达设备的物理动作可能已执行，撤销不能撤回。成功发送 WOL 也不等同于电脑已经开机。

## 兼容限制

旧 `/api/v1/*` 仍使用旧共享凭据，LAN 配对也保留既有长期密钥，以兼容已部署设备。后续逐客户端 LAN 授权尚未替代旧协议。服务主机、路由器管理员及已授权客户端属于各自的信任边界，不能向不可信人员共享其私有数据。

本地自动测试验证身份、路由和重放边界，不证明实际服务器网络、防火墙、设备固件或完整公网部署已经验收。当前待完成项见 [实现状态](architecture-v2.md)。
