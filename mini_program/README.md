# LanPower 微信小程序

源码版首页已升级为 Cloud v2：网页生成一次性授权二维码，手机扫码后选择电脑；在线 Windows 无需路由器网关即可远程控制。为选中电脑关联独立局域网配对后自动优先局域网；各电脑的唤醒 MAC 与广播地址可在页面填写。[小程序 v2 使用和验证说明](../docs/mini-program-v2.md) 列出完整流程与尚需微信真机验收的项目。

当前小程序版本为 `2.0.0`、协议版本为 `2`；首页显示版本，首次 Cloud 授权会同时上报版本供管理页面查看。

下文介绍保留的“仅使用局域网 / 旧版连接”入口。该入口继续读取原有配对信息。

这个手机端由我们自己编写。家中局域网里，电脑关闭时小程序用 UDP 发送 WOL 魔术包；电脑在线时直接调用 LanPower 服务。配置远程配对后，局域网请求不可达时自动查询 Cloud，并通过 AX3000T Gateway 完成唤醒和电源操作。当前局域网 WOL 参数仍针对网卡 `02-11-22-33-44-55`、广播地址 `192.168.1.255`。

## 在 iPhone 上预览

1. 仓库中的 `project.config.json` 使用公开占位值 `touristappid`。在本机微信开发者工具里设置自己的小程序或测试号 AppID；个人项目设置保存在被 Git 忽略的 `project.private.config.json`，不要提交。项目没有使用或保存 AppSecret。
2. 在本机的微信开发者工具中导入此目录，用持有该 AppID 的微信账号登录，编译后点“预览”，用 iPhone 微信扫描开发者工具给出的二维码。
3. 电脑上打开 `http://127.0.0.1:48211/setup`。在小程序里点“扫描配对二维码”，扫描电脑屏幕上的二维码。小程序只把配对信息保存在本机微信存储中。
4. iPhone 要连接与电脑有线网口同一个局域网的 Wi-Fi。首次弹出微信本地网络访问提示时，选择允许。

要启用远程模式，先按 [Cloud 说明](../cloud_remote/README.md) 部署服务并生成私有配对码，再点小程序中的“扫描远程配对码”。局域网和远程凭据分别存储在微信本机；Cloud 只收到独立远程凭据，不会收到 Windows LAN Token。请在微信平台配置实际 HTTPS 域名并用真机测试 5G。

配对完成后，先看“在线”状态。想测试唤醒时，先让电脑睡眠，在小程序里点“开机”；成功后再依次测试休眠和关机。每次都可用同一个小程序唤醒。

## 已知条件

- 电脑关机时，状态请求会失败，但小程序仍能打开并发送唤醒包；最多等待 60 秒显示开机状态。即使随后 Cloud 请求也失败，只要本地配对仍在，“开机”按钮就继续使用局域网 WOL，并提示远程不可用。
- 当前唤醒包发送到 `255.255.255.255` 和 `192.168.1.255` 的 UDP 9 端口。如果以后更换网卡或局域网网段，要同步修改 `utils/wol.js` 并重新预览。
- 电脑的电源操作走 `http://电脑局域网地址:48211`。本机 iPhone 微信预览版已实际验证局域网连接、睡眠唤醒和关机后开机。
- 未配置远程配对时，仍只支持同一局域网。远程链路已在代码中实现，且一套实际部署已在 iPhone 5G 下验证远程在线、睡眠和唤醒；仓库不包含实际 Cloud 域名与凭据。其他远程电源动作尚未逐项真机验证。

技术依据：[微信小程序网络说明](https://developers.weixin.qq.com/miniprogram/dev/framework/ability/network.html)、[UDP 发送接口](https://developers.weixin.qq.com/miniprogram/dev/api/network/udp/UDPSocket.send.html)。
