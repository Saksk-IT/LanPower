# LanPower 微信小程序

这个手机端由我们自己编写。电脑关闭时，小程序用 UDP 发送 WOL 魔术包；电脑在线时，同一个界面调用本机已安装的 LanPower 服务完成睡眠、休眠、重启和关机。使用时不需要 WakeCast。当前只针对这台电脑及家中局域网：网卡 `02-11-22-33-44-55`，广播地址 `192.168.1.255`，电脑地址由配对二维码提供。

## 在 iPhone 上预览

1. `project.config.json` 已填入你提供的小程序测试号 AppID。项目没有使用或保存 AppSecret。
2. 在本机的微信开发者工具中导入此目录，用持有该测试号的微信账号登录，编译后点“预览”，用 iPhone 微信扫描开发者工具给出的二维码。
3. 电脑上打开 `http://127.0.0.1:48211/setup`。在小程序里点“扫描配对二维码”，扫描电脑屏幕上的二维码。小程序只把配对信息保存在本机微信存储中。
4. iPhone 要连接与电脑有线网口同一个局域网的 Wi-Fi。首次弹出微信本地网络访问提示时，选择允许。

配对完成后，先看“在线”状态。想测试唤醒时，先让电脑睡眠，在小程序里点“开机”；成功后再依次测试休眠和关机。每次都可用同一个小程序唤醒。

## 已知条件

- 电脑关机时，状态请求会失败，但小程序仍能打开并发送唤醒包；最多等待 60 秒显示开机状态。
- 当前唤醒包发送到 `255.255.255.255` 和 `192.168.1.255` 的 UDP 9 端口。如果以后更换网卡或局域网网段，要同步修改 `utils/wol.js` 并重新预览。
- 电脑的电源操作走 `http://电脑局域网地址:48211`。本机 iPhone 微信预览版已实际验证局域网连接、睡眠唤醒和关机后开机。
- 5G/外网控制尚未加入。

技术依据：[微信小程序网络说明](https://developers.weixin.qq.com/miniprogram/dev/framework/ability/network.html)、[UDP 发送接口](https://developers.weixin.qq.com/miniprogram/dev/api/network/udp/UDPSocket.send.html)。
